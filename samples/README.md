# Synthetic samples

Everything in this directory is fictional and generated by `scripts/generate_samples.py`.
Do not edit by hand: change the generator and re-run it. `tests/test_samples.py` fails if the
committed files drift from the generator output.

- `claims/`: claim submissions, the pipeline input.
- `documents/`: plain-text renderings of synthetic receipts.
- `extractions/`: recorded extraction results, one per document. They simulate the output of a
  document-analysis service; no OCR is performed anywhere in this repository.
- `expected_outcomes.json`: the outcome each claim must produce in a batch run.
